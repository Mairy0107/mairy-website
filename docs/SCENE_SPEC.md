# 场景规格与摆放

## 坐标与构图

世界坐标采用 Y 向上，店铺正面朝 +Z，右侧道路位于 +X。底座为 16 × 16 的完整正方形，范围 X / Z 为 -8 至 +8；侧壁位于 Y=-0.805 至 -0.155，路面略高于底座顶层。人行道顶面 Y≈0.16，建筑和道具以人行道为基础放置。

便利店中心位于 (-1.65, 0.17, -2.05)，建筑宽约 7.7、深约 4.7、高约 3.9。前街位于 Z>2.8，右侧小巷位于 X>3.4。建筑稍偏左后，为前方斑马线与右侧停车位留下空间；不同高度的雨棚、屋顶、路灯、电线杆形成层次。

默认相机位于 (19, 16, 23)，观察目标为 (0, 1.1, 0)，从右前上方完整展示模型。镜头不自动旋转，用户可自由操作。

## 雨夜与动画

共 2400 条细雨，在底座上方约 11 个单位的范围内循环下落，带有轻微风向倾斜。雨丝不投影、不参与深度写入。屋顶及雨棚下方的雨丝通过空间遮罩隐藏，避免直接落入店内。

34 组实例化圆环分布在前街和右侧小巷，按各自相位扩散和变暗。积水倒影采用每帧更新的平面反射；招牌绿光、贩卖机粉光、路灯暖光在路面形成克制的颜色层次。环境保持深蓝夜色，墙面与道具仍有清晰的卡通明暗。

## 交互及边界

鼠标左键旋转，滚轮缩放，右键 / 中键平移；触屏单指旋转、双指缩放 / 平移。镜头缩放距离 12–52，极角限制在 0.16 至 0.475π 之间。右侧提供中文半透明面板，可选择十类物件、切换三款配色、绽开 / 还原并保存到服务器。悬停物件显示中文名称；底座、天气、路面不参与配色切换。不添加坐标轴、FPS、logo、水印或调试面板。

还原状态下所有建筑、道具和道路设施都位于底座范围内；绽开时主要物件向场景中心外侧平滑分离，底座外仅保留纯色夜景背景与轻雾，不引入远景城市或额外地面。

## 入场显现

首次进入时，`src/scene/reveal.ts` 用约 5 秒的世界高度渐变遮罩，让整个景观从底座向上柔和显现；遮罩以平滑像素覆盖率实现，不增加页面蒙层或 UI，并覆盖轮廓线、实例化商品、雨丝、涟漪与积水倒影。

底座和道路首先出现，随后是便利店主体、招牌、雨棚，再以约 0.17 秒间隔依次显现贩卖机、自行车、雨伞架、垃圾桶、公告栏、护栏、路灯、电线杆与小巷道具。各组以柔和缓出完成轻微上升和缩放，局部光源同步淡入。入场期间刷新遮罩阴影，结束后恢复原材质、精确摆放与静态阴影，释放临时材质。

动画跟随页面可见时间推进，后台暂停、回到页面后继续；全程可使用轨道控制。系统启用“减少动态效果”时直接展示完整场景，不播放入场动画。
